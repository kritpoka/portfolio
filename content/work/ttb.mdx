<Section n="01" title="TL;DR" id="tldr">

- Built in-house developer tools — CSV↔JSON, regex tester, QR generator — so engineers stopped pasting data into outside websites that didn’t fit bank policy.
- Replaced the Business Analysis team’s versioned Excel files with one Activity Log on Firestore.
- On the enterprise platform team: helped move a monorepo to micro-frontend polyrepos and shipped real-time notifications and a cross-tab idle timeout.

</Section>

<Section n="02" title="Context & problem">

Two everyday problems. Engineers were using public websites for routine tasks like converting CSV or testing a regex — fine elsewhere, not inside a bank. And the Business Analysis team tracked activity in Excel files passed around as versions, so nobody was sure which copy was current.

</Section>

<Section n="03" title="My role">

Software Engineer Tech Intern in the ttb spark Tech & Data Internship. I built the developer tools and the Activity Log, and contributed features to the enterprise platform. On the Activity Log I owned the work from requirements through navigation, single-device sign-in, the data dictionary, version log, caching and export. For the developer tools I added the CSV↔JSON, regex and QR features, the shared analytics component and the Fastlane + Melos lanes. On the platform team I helped migrate code between releases, built the unread-notification feature from a Jira spec, and made the idle timeout work across tabs.

</Section>

<Section n="04" title="Users & research">

Internal engineers, the Business Analysis team, and users of the tablet platform. Activity Log requirements came straight from the Business Analysis team; platform features were built from specifications in Jira.

</Section>
